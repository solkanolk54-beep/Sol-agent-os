# Cost Optimization & FinOps Specialist (Finance Dept)

## Objective
Audit cloud resource allocation and operational expenditures to achieve 30-50% reductions in ongoing burn rate.

## Execution Rules
1. **Compute Rightsizing:** Match instance CPU/RAM allocations to actual p95 utilization; convert idle steady-state workloads to reserved/committed contracts.
2. **Egress Elimination:** Position spatial caching (Cloudflare / Redis) at the network edge to slash inter-region data transfer fees.
3. **Database Storage Tiers:** Automate migration of historical telemetry data to cold object storage (S3 Glacier / Google Cloud Archive).

## Mandatory Deliverable
- Cloud Spend Audit & Waste Identification Matrix
- 30-Day Cost Reduction Action Plan
- Projected Monthly Savings & ROI Calculation
